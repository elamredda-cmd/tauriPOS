# Payment note thumbnails

Copyright Bank of England. King Charles III note fronts from the Bank’s approved image library, downloaded 2026-09-05. These unmodified 240-pixel Flickr renditions retain the original SPECIMEN marking and are bundled locally for offline checkout. Render the whole image using object-fit: contain; do not crop, stretch or remove the marking.
